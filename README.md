## 🛠 Tech Stack

### Frontend

- React 18
- Vite
- React Router
- Axios
- Chakra UI
- Framer Motion

### Backend

- Node.js
- Express.js
- Sequelize ORM
- PostgreSQL
- JWT
- bcrypt

## ✨ Features

- User registration and authentication
- Product catalog
- Product creation
- Product deletion
- Shopping cart
- REST API
- PostgreSQL database
